В этом каталоге сохранён полный архив переносимых материалов из `storage`: исходные JSON-корпуса, результаты расчётов, промежуточные исследования и журналы проверок.

Для восстановления из корня проекта:

```sh
python3 -m scripts.restore_storage
```

Команда использует только стандартную библиотеку Python, проверяет SHA-256 частей архива и каждого файла, восстанавливает исходные пути `storage/...` и сохраняет уже существующие совпадающие файлы. Отличающиеся локальные файлы не перезаписываются; для независимой проверки используйте `--destination /путь/к/пустому/каталогу`.

Архив разделён на части размером до 48 МиБ. `manifest.json` содержит их порядок и контрольные суммы всех исходных файлов. Локальные SQLite-базы, файлы блокировок, окружения, кеши и настройки редактора в архив не входят; для переносимого анализа сохранены JSON-экспорты и результаты.
