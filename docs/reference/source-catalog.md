# Каталог источников для анализа технологий

Актуальность проверки: 25 сентября 2026 года. «Доверенный» здесь означает,
что источник можно использовать **для указанного факта** с проверяемой ссылкой,
датой, правилами сбора и явным охватом. Каталог или фонд не удостоверяет
истинность научного результата. Материалы одной работы из разных каталогов
объединяются по DOI или URL, когда такая связь известна.

Статус «веб» означает автоматический опрос в основном анализе. Все веб-источники
открыты без ключей API; владелец выбирает в панели управления страны, из
источников которых берутся сведения, и может выключить отдельные источники
(вкладка «Источники и языки»). Страна источника — страна издателя или ведущей
организации; «Международные» — каталоги без одной страны. «Импорт» —
проверяемая загрузка файла на экране «Сигналы из нескольких источников».
«Кандидат» означает проверенный публичный канал, для которого автоматический
адаптер ещё не включён.

## Исследования, разработки и обсуждения

| Источник | Что подтверждает | Статус и ограничение |
| --- | --- | --- |
| [Crossref](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | Регистрацию DOI и метаданные работ | Веб, научный поиск; запись не удостоверяет рецензирование. |
| [OpenAlex](https://docs.openalex.org/) | Библиографические связи и фон области | Веб, научный поиск; включает записи из других каталогов. |
| [Europe PMC](https://europepmc.org/RestfulWebService) | Биомедицинские статьи и препринты | Веб, не более 50 за запрос; в помесячный ряд допускается только подтверждённая точная дата. |
| [PubMed E-utilities](https://www.ncbi.nlm.nih.gov/books/NBK25497/) | PMID, даты и медицинские предметные рубрики | Кандидат: публичный API с лимитом запросов; многие записи уже есть в Europe PMC, объединять по PMID/DOI. |
| [Semantic Scholar Academic Graph](https://api.semanticscholar.org/api-docs/) | Библиографию и цитирования | Веб, без ключа: общий лимит запросов, при отказе охват помечается; значительное пересечение с OpenAlex/Crossref. |
| [OpenAIRE Graph](https://graph.openaire.eu/docs/apis/graph-api/overview/) | Исследовательские работы, ПО, данные и связи с проектами | Кандидат: публичный API; записи пересекаются с Crossref, Zenodo и CORDIS, требуется объединение по DOI и ID проекта. |
| [arXiv](https://info.arxiv.org/help/api/user-manual.html) | Препринты, дату первой версии и основную предметную категорию | Веб и Atom-импорт; категория описывает область, а не качество. | [bioRxiv](https://api.biorxiv.org/) | Биомедицинские препринты | Веб, ограниченная свежая выборка; нет рецензирования. |
| [OpenReview](https://docs.openreview.net/reference/api-v2/openapi-definition) | Публичные записи открытого рецензирования | Веб; если дата публичного доступа неизвестна, дата создания помечается отдельно. |
| [Zenodo](https://developers.zenodo.org/) | Публичные исследовательские материалы и наборы данных | Веб; тип записи не доказывает независимую проверку. |
| [DataCite REST](https://support.datacite.org/docs/rest-api) | DOI и метаданные наборов данных и программ | Кандидат: публичный API с [лимитом запросов](https://support.datacite.org/docs/rate-limit); часто пересекается с Zenodo/OpenAIRE, регистрация DOI не удостоверяет качество. |
| [EPO OPS](https://www.epo.org/en/searching-for-patents/data/web-services/ops) | Патентные семьи и заявки | При наличии ключей; заявка не равна внедрённой технологии. |
| [Роспатент: открытые данные](https://online.rospatent.gov.ru/open-data/) | Российские патентные записи | Кандидат: портал сообщает об открытых API, но доступный стабильный endpoint не подтверждён; объединять с EPO по номеру или семейству. |
| [Реестр российского ПО](https://reestr.digital.gov.ru/reestr/) | Включение продукта, правообладателя и класса ПО в официальный реестр | Кандидат для разрешённой выгрузки; дата регистрации не равна дате разработки или внедрения. |
| [ClinicalTrials.gov API](https://clinicaltrials.gov/data-api/api) | Регистрацию клинических исследований и их статусы | Кандидат для медицинских направлений; регистрация не означает успешный результат. |
| [NIST RSS](https://www.nist.gov/coo/nist-rss-feeds), [MIT Research News](https://news.mit.edu/rss) и [Horizon Magazine](https://projects.research-and-innovation.ec.europa.eu/en/horizon-magazine/republish-our-stories) | Сообщения организаций о разработках | Веб, свежие ленты; новости не дублируются как независимые исследования. |
| [GitHub Search](https://docs.github.com/en/rest/search/search) | Публичные репозитории по теме | Веб; репозиторий показывает разработку, не качество результата. |
| [Хабр RSS](https://habr.com/ru/docs/help/lenta/) и [Hacker News](https://hn.algolia.com/api) | Технические обсуждения | Веб: Хабр ищет по русской формулировке запроса (поисковая RSS, при отказе — свежая лента), Hacker News — поиском Algolia по всему архиву (при отказе — свежая выборка); низкий вес, без научного подтверждения. |
| [GDELT DOC API](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/) | Обнаружение новостных сообщений | Веб; дата индексации не подменяет дату публикации; фильтр стран владельца передаётся как `sourcecountry`. |
| [Google News RSS](https://news.google.com/) | Новостные публикации по странам | Веб, без ключа: у каждой выбранной страны своё издание и язык запроса (русскому — русская формулировка); срез поисковой выдачи, не весь архив. |
| [DOAJ](https://doaj.org/api/docs) | Статьи журналов открытого доступа | Веб, без ключа; страна записи — страна журнала, фильтр стран применяется в самом запросе; известен только год публикации. |

| [HAL](https://api.archives-ouvertes.fr/docs/search) | Открытый архив французских исследований | Веб, без ключа (Solr); неполная дата сохраняется как год. |

| [dblp](https://dblp.org/faq/How+to+use+the+dblp+search+API.html) | Публикации по информатике | Веб, без ключа; только год публикации. |
| [ChemRxiv](https://chemrxiv.org/engage/chemrxiv/public-api/documentation) | Препринты химии | Веб, без ключа; нет рецензирования. |

| Источник | Мера | Статус и условие |

| [Yandex Wordstat GetDynamics](https://aistudio.yandex.ru/en/docs/search-api/operations/wordstat-getdynamics) | Помесячные `count` и `share` для заданной фразы, региона и устройств | API по ключу или CSV-импорт; платный вызов учитывается отдельным бюджетом. |

| [Google Ads Keyword Planning](https://developers.google.com/google-ads/api/docs/keyword-planning/generate-historical-metrics) | Приблизительные помесячные поиски по ключам за доступный период | Кандидат: требуется доступ к Google Ads API и его квотам. |

## Финансирование и вложения

Денежные ряды хранятся отдельно по валюте и смыслу суммы: **объявленные
обязательства**, **фактические выплаты**, **привлечённый капитал** и **остатки
портфеля** нельзя складывать. Совпадение названия проекта и технологии требует
проверки; грант и портфельная позиция не являются венчурной сделкой.

| Источник | Что можно проверить | Статус и ограничение |
| --- | --- | --- |
| [NIH RePORTER](https://api.reporter.nih.gov/) | Дату, тему и сумму годовой награды NIH | Веб, одна страница до 50 записей, явная неполнота; отдельный блок, не научный балл. [Рекомендация API](https://api.reporter.nih.gov/) — не чаще одного запроса в секунду. |
| [CORDIS Horizon Europe](https://data.europa.eu/data/datasets/cordis-eu-research-projects-under-horizon-europe-2021-2027?locale=en) | Вклад ЕС в исследовательский проект | CSV-импорт; заявленная сумма не равна фактическим платежам. Автоматический [DET API](https://cordis.europa.eu/about/dataextractions-api) требует ключ. |
| [Разрешённая выгрузка инвестиционных событий](../../app/pilot/multisource/capital.py) | Конкретную сделку, дату, сумму, валюту и источник | CSV-импорт с проверкой колонок и прав на хранение. |
| [SBIR/STTR](https://www.sbir.gov/data-resources) | Государственные награды технологическим малым компаниям США | Кандидат: доступны полные файлы; [API на обслуживании](https://www.sbir.gov/api). |
| [UKRI Gateway to Research](https://gtr.ukri.org/resources/api.html) | Финансируемые проекты, организации и объявленные суммы Великобритании | Кандидат: открытый API; [стоимость проекта](https://www.ukri.org/publications/gateway-to-research-guide/a-guide-to-gateway-to-research/) не равна выплате, переносы проектов могут дать двойной счёт. |
| [USAspending API](https://api.usaspending.gov/docs/endpoints) | Федеральные гранты, контракты, обязательства и выплаты США | Кандидат; необходимо различать `obligation` и `outlay`. |
| [SEC Form D](https://www.sec.gov/data-research/sec-markets-data/form-d-data-sets) | Капитал, привлечённый эмитентами и частными фондами | Кандидат, квартальные файлы; [поправки](https://www.sec.gov/data-research/statistics-data-visualizations/regulation-d-offerings) требуют расчёта прироста, инвесторы не названы. |
| [CalPERS PE Fund Performance](https://www.calpers.ca.gov/investments/about-investment-office/investment-organization/pep-fund-performance) и [NYSTRS Private Equity](https://www.nystrs.org/investments/portfolio/private-equity-activity/) | Обязательства публичных пенсионных фондов перед конкретными PE/VC-фондами | Кандидаты для проверки раскрытий: таблица NYSTRS содержит фонд, обязательство, внесённую сумму и тип вложения, в том числе Growth/Venture Capital. Это квартальный снимок с [задержкой публикации](https://www.nystrs.org/investments/portfolio/), а не сделки по месяцам или список компаний фонда. Документированный CSV/API не подтверждён. |
| [EIF Equity Portfolio](https://www.eif.org/files/attachments/eif-equity-portfolio-backed-active-funds.pdf) | Поддержанные EIF фонды и их специализацию | Кандидат; опубликован PDF, универсального ряда сумм сделок нет. |
| [SEC Form 13F](https://www.sec.gov/data-research/sec-markets-data/form-13f-data-sets) и [Form N-PORT](https://www.sec.gov/data-research/sec-markets-data/form-n-port-data-sets) | Публичные позиции управляющих и фондов | Кандидаты только для **остатков портфеля**; изменение позиции не равно новому вложению в технологию. |
| [РНФ](https://rscf.ru/project/) и [РФПИ](https://www.rdif.ru/Eng_Map/) | Российские проекты и отдельные инвестиционные кейсы | Кандидаты для ручной проверки; полный открытый помесячный API сумм не подтверждён. |
| [Фонд содействия инновациям](https://fasie.ru/competitions/) | Победителей российских технологических конкурсов | Кандидат: опубликованные списки не подтверждают подписанный грант или перечисление денег; общего API не подтверждено. |

Параллельный опрос выполняется между независимыми площадками, с отдельными
ограничениями каждой. Платный Wordstat вызывается только явно с бюджетом; arXiv
нужен общий ограничитель на уровне всех установок. Неполная выдача, отсутствие
ключа или ошибка источника показываются как неизвестный охват, а не как нулевой
интерес или нулевое финансирование. Правило `100/100` в
[помесячной методике](../methodology/monthly-evidence.md) требует подтверждённого полного
охвата каждого месяца и не является вероятностью успеха технологии.
