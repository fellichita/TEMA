# Запуск из исходников на MacBook

Эта версия рассчитана на **MacBook с Apple Silicon (M1/M2/M3/M4 и новее),
macOS 14 или новее**. Проверьте процессор и macOS через меню Apple → «Об этом Mac».

**Intel Mac пока не поддерживается:** закреплённый ONNX Runtime 1.29.0 не публикует
macOS Intel wheel. Запускатель обнаруживает несовместимость до загрузки библиотек.
Используйте нативный arm64 Python.
Основание — [файлы официального выпуска ONNX Runtime](https://pypi.org/project/onnxruntime/1.29.0/#files).

## Запуск и разработка из исходников

Скопированная `.venv` с первого Mac не переносима: окружение создаётся заново на втором.

1. Установите **обычный Python 3.13 с Tkinter** через `macOS 64-bit universal2 installer`
   с [python.org](https://www.python.org/downloads/macos/). Экспериментальную
   free-threaded сборку не выбирайте. Для Homebrew нужны `python@3.13` и
   `python-tk@3.13`; используйте нативный arm64 Python.
2. Для компиляции проверенной SQLite установите Xcode Command Line Tools:

   ```sh
   xcode-select --install
   ```

3. Скачайте [исходники проекта](https://github.com/fellichita/TEMA/tree/main)
   через **Code → Download ZIP** и распакуйте в обычную локальную папку с правом
   записи. Либо клонируйте именно нужную ветку:

   ```sh
   git clone --branch main --single-branch https://github.com/fellichita/TEMA.git
   ```

4. Дважды откройте **«launchers/macos/desktop.command»**. При первом старте окно
   Terminal покажет установку закреплённых библиотек и сборку SQLite. Дождитесь
   окна приложения. При следующих стартах готовое окружение проверяется локально;
   библиотечные обновления и сетевые запросы без необходимости не выполняются.

Большие веса моделей не хранятся в Git. Подготовьте их из корня проекта:

```sh
.venv/bin/python -m scripts.setup_models
```

Для локального AI дополнительно выполните `python -m scripts.install_local_llm`;
подробности — в [руководстве по локальному AI](local-ai.md).

Если файл `.command` потерял исполняемый атрибут при распаковке, откройте Terminal,
перейдите в распакованную папку и выполните:

```sh
bash "launchers/macos/desktop.command"
```

Запускатель работает независимо от текущей папки Terminal, включая пути с русскими
буквами и пробелами. Он меняет только `.venv` и `build` внутри проекта, кеш загрузок
библиотек и небольшой временный файл блокировки. Системный Python и старую рабочую
версию приложения он не заменяет. Личные данные самого приложения сохраняются в
системной папке, указанной ниже. После сетевого сбоя запустите тот же файл снова.

Для диагностики без установки и открытия приложения:

```sh
bash "launchers/macos/desktop.command" --check
```

Для подготовки окружения без открытия окна:

```sh
bash "launchers/macos/desktop.command" --install-only
```

Свою отдельную библиотеку можно выбрать так:

```sh
bash "launchers/macos/desktop.command" -- --data-dir "storage/Моя библиотека"
```

После обновления исходников снова запустите `.command`: если закреплённые версии
библиотек изменились, окружение будет приведено в соответствие. Несовместимую или
повреждённую `.venv` запускатель не удаляет: переименуйте только её и повторите
запуск. Анализы находятся вне `.venv` и не потеряются.

Если установка Python сообщает об ошибке проверки TLS-сертификата, выполните
поставляемый Python.org файл `Install Certificates.command` в папке установленного
Python 3.13. Не отключайте проверку сертификатов и не добавляйте `--trusted-host`.

## Как перенести свои анализы

GitHub содержит исходники. Он не синхронизирует личные анализы,
загруженные отчёты, ключи API и настройку бюджета между компьютерами.

**Всю библиотеку переносите через встроенную резервную копию:**

1. На первом Mac дождитесь завершения или отмените активный анализ. Во вкладке
   **«Новый анализ»** прокрутите вниз и нажмите **«Резервная копия»**.
2. Дождитесь сообщения о проверенной копии. Передайте созданный файл лично,
   например через AirDrop или USB. В нём могут быть загруженные вами полные тексты;
   не публикуйте его в открытом репозитории.
3. На новом Mac откройте **«Новый анализ» → «Восстановить копию»**, выберите файл и
   родительскую папку. Приложение создаст новую библиотеку и переключится на неё.
   Уже существующую библиотеку восстановление не затирает.
4. Заново настройте ключи и подготовьте локальные модели.
   До новых платных AI-запросов откройте **«Расходы и сверка»** и сопоставьте
   восстановленный учёт с кабинетом провайдера. Локальные лимиты двух Mac не
   объединяются автоматически в общий бюджет.

**Отдельный результат:** выберите анализ в истории → **«Экспорт результата»** →
перенесите `.trendresult` → на новом Mac нажмите **«Открыть файл результата»**.
Это переносимый снимок для просмотра и проверки доказательств, не полная библиотека
заданий. Контрольные суммы подтверждают целостность, но не удостоверяют автора.

По умолчанию приложение хранит данные здесь (имя сохранено для совместимости):

```text
~/Library/Application Support/Trendanalizer Pilot main2
```

Не копируйте открытые SQLite-файлы вручную между работающими приложениями.
Резервная копия создаётся согласованно штатной функцией приложения. Не выбирайте
библиотеку старой версии как рабочую папку main2.
