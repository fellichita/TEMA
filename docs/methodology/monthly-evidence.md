# Помесячные свидетельства в веб-результате

Методика `web-monthly-evidence/1.0.0` строит описательный ряд материалов по теме
анализа. Это отдельный показатель: он не меняет научную категорию тренда,
«Уверенность в тренде» или балл смыслового соответствия публикации запросу.
Веб-API возвращает периоды 6, 12, 24 и 36 календарных месяцев до даты
сохранённого анализа включительно.

## Единица счёта и коэффициенты

Сначала API объединяет **весь найденный пул**, а уже затем выбирает публикации
для показа в браузере. В пул входят материалы этапа обнаружения научного анализа
и утверждённых дополнительных источников; вспомогательные исторические документы
не добавляются. Совпадающие DOI и URL связывают записи разных каталогов. Это
убирает распознанные повторы, но не гарантирует, что материалы с разными DOI и URL
не описывают одно исследование. Для каждого материала сохраняются все найденные
`source_ids`; в помесячную сумму он входит **один раз**, с наибольшим из их
коэффициентов. Поэтому сумма чисел по источникам может превышать число уникальных
материалов. [Cochrane](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04)
рекомендует считать исследование, а не число его сообщений.

| Источник | Коэффициент | Класс |
| --- | ---: | --- |
| Crossref, OpenAlex, Europe PMC | 1,00 | Научный индекс |
| EPO | 0,90 | Патент |
| arXiv, bioRxiv | 0,85 | Препринт |
| OpenReview | 0,80 | Препринт |
| Zenodo | 0,70 | Исследовательский материал |
| Аналитические отчёты | 0,60 | Отчёт |
| NIST News | 0,70 | Новость учреждения |
| MIT Research News | 0,65 | Новость учреждения |
| Horizon Magazine | 0,60 | Новость учреждения |
| GitHub | 0,50 | Репозиторий |
| GDELT | 0,35 | Агрегатор новостей |
| Hacker News, Хабр | 0,25 | Сообщество |

Это **заданные правилами веса**, а не измеренные вероятности достоверности.
Наличие статьи в научном индексе само по себе не подтверждает рецензирование,
воспроизводимость или истинность результата. Препринт также не равен прошедшей
рецензирование работе: [bioRxiv](https://www.biorxiv.org/content/what-unrefereed-preprint)
предупреждает об этом прямо. Метаданные Crossref могут связывать препринт с
журнальной версией через
[`isPreprintOf`](https://www.crossref.org/documentation/schema-library/markup-guide-metadata-segments/relationships);
проверка такой связи важна для дальнейшего улучшения дедупликации.

## Месяцы, охват и сглаживание

Для месяца показываются число уникальных материалов, сумма их коэффициентов и
разбивка по источникам. Используется только дата **публикации** с точностью до
месяца или дня. Записи только с годом, неизвестной датой, датой обнаружения
агрегатором или противоречащими датами не распределяются по месяцам; их число
видно в `excluded`. Месяц даты анализа ещё не завершён. Если в месяце ничего не
найдено, но полнота исторического охвата не доказана, значение остаётся
неизвестным (`null`), а не нулём.

Поверх исходных значений вычисляется **центрированное среднее за три месяца**:
значения предыдущего, текущего и следующего месяца делятся на три. Оно доступно
только при наличии всех трёх значений и не рассчитывается на краях периода или
рядом с незавершённым месяцем. Сглаженная линия служит для чтения графика;
проверка формы использует исходный ряд. Такое центрированное среднее описано в
[Forecasting: Principles and Practice](https://otexts.com/fpp3/moving-averages.html).

## Условие 100/100

`shape.score = 100` ставится только когда одновременно выполнены все условия:

1. Подтверждён полный исторический охват **каждого** месяца выбранного периода,
   а учтённые источники завершили сбор без достижения лимита.
2. Есть не менее восьми полных месяцев, трёх уникальных материалов и двух разных
   классов основных источников материалов.
3. Для исходного ряда завершённых месяцев квадратичная модель даёт
   `R² ≥ 0,95` и выигрывает у линейной по `R²` минимум на `0,05`.
4. Ряд не убывает; квадратичный коэффициент положителен, а наклон в начале
   интервала положителен. Таким образом, правило ищет ускоряющийся рост, а не
   любую дугу параболы.

Если хотя бы одно условие не выполнено, `score = null`, а причины перечислены
в `shape.gate_reasons`; промежуточных процентов методика не выдаёт. Два класса
источников не доказывают независимость исследовательских групп. Высокий `R²`
сам по себе также не подтверждает пригодность модели —
[NIST требует проверять остатки](https://www.itl.nist.gov/div898/handbook/pmd/section4/pmd44.htm).
**100/100 означает выполнение заданного правила формы, а не 100% вероятность
существования или будущего успеха тренда.** Для вероятностной интерпретации нужна
отдельная калибровка на отложенных во времени результатах;
[документация scikit-learn](https://scikit-learn.org/1.8/modules/calibration.html)
различает оценку модели и калиброванную вероятность.

Сейчас веб-API не подтверждает полноту исторического охвата для каждого месяца,
поэтому передаёт в расчёт значение по умолчанию `period_coverage_complete=False`.
Помесячный ряд остаётся описательным, а 100/100 через веб-результат пока не
присваивается.
